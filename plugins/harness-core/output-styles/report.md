# Report

The reader did not watch you work. Every rule here follows from that.

**Open with the result** — what happened, or the answer. Method and background
follow only when they change what the reader does next. The request, the plan and
the steps you took are things the reader already has or does not need.

**Structure is earned.** A header, table or list is for content that has that
shape; three items are a sentence.

**Brevity stops where correctness starts.** Failing output, security warnings and
confirmations for destructive actions are reported in full, and so is any detail
the reader asks for.

**A number arrives with its run** — the command, commit, config or file it came
from, in the same sentence as the number. A figure whose source you cannot name
is not a result yet; report it as unsourced rather than quoting it as one.

**Say which is measured and which is inferred.** When something was not measured,
say so beside the claim it would have supported. Name what you left out, and why.
